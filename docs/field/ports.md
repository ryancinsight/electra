# Routed rail and piezoelectric port qualification

For a uniform copper segment the solver derives resistance at ambient from the Euclidean endpoint distance, width, thickness and resistivity. It solves the constant-current steady balance with linear temperature coefficient and a single specified thermal resistance to ambient. A 60 × 80 mm displacement, 0.5 mm wide, 35 µm thick, with ρ = 1.724 × 10⁻⁸ Ω m, α = 0.00393/K and θ = 60 K/W is checked against a fixed-point thermal iteration at −2, 0 and +2 A. Thermal runaway is rejected. Each segment has its own thermal path; mutual heating between segments requires a separate model.

The Metis editor loads a sibling `.rail` file on `field drop 1` or `field thermal 2`. Each line after the header represents one registered sampling cell, and contains the net ID, trace displacement dx/dy (mm), width (mm), copper thickness (µm), resistivity (Ω m), α (/K), θ (K/W) and applied current (A). The header carries rows, columns, origin x/y (mm) and pitch (mm). The map is row-major. Blue encodes absolute drop from 0 to 0.5 V, red encodes rise from 0 to 50 K. A click reports signed drop and temperature rise at the cell centre. Two borrowed Iris scalar fields serve rendering and readback. Use `field off` to return to the schematic curve view. [Example map](../../examples/field/two-rails.rail)

The Windows replay clicks the upper-right cell at both magnifications and checks net 7, board position (13, 21) mm, voltage in V and rise in K against an independently iterated heat balance. Run the existing native schematic workflow or its local Windows replay, and `cargo test -p electra-board-field --locked` for the headless balance.

The nominal single-mode Butterworth–Van Dyke port uses Rm = 8 Ω, Cm = 100 pF, Lm = 1/[(2π × 1 MHz)² Cm] and C0 = 1 nF. The 2 V RMS sweep covers 950 kHz–1.15 MHz in 10 Hz steps. The fixture compares every impedance magnitude and dissipated power with independently summed quadrature currents. Kwavers supplies the independent lossless resonance landmarks. With damping, the minimum is 7.97990 Ω at 999.870 kHz and the maximum is 2885.73 Ω at 1048.930 kHz. At motional series resonance the dissipated power is 0.500 W. These are electrical predictions for the declared components. A physical transducer requires measured parameters and its own impedance sweep.

Run `cargo test --locked --manifest-path integrations/place-study/Cargo.toml --test piezo_port -- --nocapture`.
